# Installed AI Workflow

- Treat the project-root `AGENTS.md` as the repository rule source and read it before project work.
- When `ai/` exists, use `ai/tool/ai_setup_check.sh` to verify and auto-detect the Project Adapter before relying on project-specific workflow facts.
- Keep Core protocol and Gates, Project Adapter facts, Developer Role behavior and Runtime evidence separate.
- Use the installed `/grill-me`, `/grill-with-docs`, `/to-prd`, `/to-task-cards` and `/handoff` Skills only within their declared trigger boundaries.
- Do not treat Coding Done as QA-ready without the required self-test evidence and manual verification status.
