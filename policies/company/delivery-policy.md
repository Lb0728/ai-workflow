# Company Delivery Policy

- Coding Done is not QA-ready.
- Real diff evidence and the required Self Test stage precede Review.
- Missing manual verification is recorded explicitly and may limit QA
  readiness.
- High-risk work preserves the existing alignment Gate.
- Commit information is a suggestion until a developer explicitly authorizes
  the Git action.
- Push is never automatic.
- Existing project Commit format and required body sections remain unchanged.
