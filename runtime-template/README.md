# Runtime Template

This is the empty Runtime layout installed at `<project>/.ai/runtime/`.

It contains:

- `tasks/`
- `states/`
- `handoffs/`
- `closeouts/`
- `defects/`

The template contains no task history, project evidence, personal paths,
credentials or production data. Runtime instances belong to the installed
project and are never part of the general Workflow release.
